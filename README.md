# Monopolist AI Economist — Кабинет экономиста

**RU:** Автоматизирует расчёт тарифной сметы для регулируемых организаций (естественных монополистов): распознаёт первичные документы, раскладывает затраты по статьям приказа №90 и считает смету — вместо экономиста, который иначе делает это вручную по сотням документов.

**EN:** Automates tariff-estimate calculation for regulated utility monopolies: it recognizes primary financial documents, classifies costs against the regulator's Order No. 90, and computes the estimate — replacing the manual, document-by-document work of a tariff economist.

---

## Проблема

Экономисты регулируемых организаций (тепло-, водоснабжение и другие естественные монополии) обязаны обосновывать тариф перед регулятором сметой, которая опирается на первичные документы — счета-фактуры, чеки, акты — и строго соответствует Правилам формирования тарифов (приказ №90). На практике это означает:

- вручную разбирать сотни разнородных документов (сканы, фото, PDF) за расчётный период;
- вручную решать, какая затрата подпадает под какой пункт приказа №90, а какая не может быть включена в тариф;
- вручную искать дубли (один и тот же счёт, поданный дважды);
- держать в голове обоснование каждой цифры на случай вопросов регулятора.

Это медленно, монотонно и легко приводит к ошибкам, которые оспаривает регулятор.

## Что делает

- Принимает документы в любом виде (фото, скан, PDF) без требования к формату.
- Распознаёт тип и ключевые поля документа (номер, дата, сумма, поставщик) через Google Vertex AI (Gemini 2.5 Flash).
- Отличает финансовые документы (счёт, чек, акт) от нефинансовых (приказ, распоряжение и т.п.) и **автоматически исключает нефинансовые документы из сметы**, не блокируя расчёт ручным вводом несуществующих сумм.
- Извлекает из каждого финансового документа все строки затрат (не только шапку).
- Классифицирует каждую затрату по статьям приказа №90 через RAG (поиск релевантных пунктов приказа в векторной базе + классификация моделью строго по найденным нормам, без домыслов).
- Убирает дубли по номеру документа.
- Считает смету детерминированным кодом (не ИИ): суммы по статьям и итог — только по затратам с признаком «учитывается»; отдельно показывает исключённое и спорное, требующее решения экономиста.
- Даёт интерфейс для ручного разбора документов, которые не удалось распознать автоматически, включая возможность вручную исключить документ из расчёта.

## Как работает

1. **Загрузка.** Экономист указывает объект/услугу, населённый пункт, период и загружает документы за расчётный период через веб-интерфейс.
2. **Распознавание (Intake).** Каждый документ уходит в n8n-воркфлоу, который через Gemini 2.5 Flash определяет тип документа и ключевые поля. Результат: документ распознан, требует ручного разбора, или (если это не финансовый документ) автоматически исключается из сметы.
3. **Извлечение позиций.** Из каждого распознанного финансового документа отдельный воркфлоу вытаскивает все строки затрат (наименование, сумма, НДС, номер, дата, поставщик).
4. **Классификация (RAG).** Каждая позиция затрат отправляется в оркестратор, который по очереди классифицирует их: ищет релевантные пункты приказа №90 в векторной базе (Pinecone) и просит модель отнести затрату к статье и признаку («учитывается» / «не_учитывается» / «спорно») строго на основании найденных норм.
5. **Расчёт сметы.** Классифицированные позиции уходят в детерминированный расчётный воркфлоу: дедупликация по номеру документа, суммирование по статьям, итог, отдельные списки исключённого и спорного.
6. **Результат.** Экономист получает смету по статьям, итоговую сумму и тариф, а также список спорных позиций, требующих его решения — каждая цифра прослеживается до исходного документа.

## Стек технологий

- **n8n** — оркестрация всего конвейера (6 воркфлоу, webhook-based)
- **Google Vertex AI, Gemini 2.5 Flash** — распознавание документов, извлечение строк затрат, RAG-классификация
- **Google Vertex AI, text-multilingual-embedding-002** — эмбеддинги для семантического поиска по приказу №90
- **Pinecone** — векторная база с текстом приказа №90 (RAG)
- **Vercel** — хостинг веб-интерфейса
- HTML / CSS / JavaScript — фронтенд

# Скриншоты

Папка для скриншотов интерфейса (`kabinet-ekonomista`), на которые ссылается
корневой `README.md`:

- `screen-upload.png` — экран загрузки документов и параметров объекта
- `screen-processing.png` — экран обработки с раскрывающимся статусом этапов
- `screen-review.png` — экран разбора документов (свайп, зум, исключение из цикла)
- `screen-result.png` — экран готовой сметы

Добавьте файлы с этими именами (или обновите пути в README.md), чтобы скриншоты
отобразились.

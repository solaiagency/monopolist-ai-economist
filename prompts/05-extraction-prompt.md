# Промпт: извлечение строк затрат из документа

Используется в воркфлоу `workflows/05-extract-positions.json`, нода «Извлечь позиции (Vertex)».
Модель: **Gemini 2.5 Flash** (Vertex AI), `temperature: 0`, `responseMimeType: application/json`.
На вход вместе с текстом промпта передаётся изображение/скан документа (`inlineData`).

```
Ты бухгалтерский OCR. На изображении первичный документ (счёт-фактура, чек, акт).
Извлеки ВСЕ строки затрат. Верни СТРОГО JSON-массив объектов с полями: name
(наименование затраты), amount (сумма числом или строкой как в документе), vat,
doc_number (номер документа), doc_date, supplier. Если поле не читается — null.
Не выдумывай. Только JSON-массив.
```

## Отличие от промпта распознавания (Intake)

Intake (`01-intake-recognition-prompt.md`) определяет тип документа и решает, идёт ли
он дальше по конвейеру. Этот промпт вызывается только для уже принятых финансовых
документов и вытаскивает каждую отдельную строку затрат (в счёте может быть несколько
позиций) — это и есть данные, которые дальше классифицируются и суммируются в смету.
